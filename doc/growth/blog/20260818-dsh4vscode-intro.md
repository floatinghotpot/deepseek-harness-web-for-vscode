## 标题

VS Code 里直接跑 DeepSeek Agent？这个扩展一键搞定 🔥

## 正文

写代码写到一半，切到浏览器看 Agent 干活，再切回来……一天来回八百次 😮💨

直到我发现这个开源扩展——**DeepSeek Harness Web for VS Code**，把 DeepSeek Harness（DSH）的完整 Web UI 直接嵌进 VS Code 编辑器标签页，边写代码边跑 Agent，一个窗口全搞定。

✨ 它有多香：

🖥️ **编辑器标签页内嵌**——DSH 对话/工作区/设置/插件全功能照搬，不遮挡资源管理器，和文件编辑并存

🔗 **与浏览器共享实例**——同一个 `~/.dsh`，会话、设置、插件两端互通，切来切去不丢上下文

📋 **剪贴板可用**——webview 里复制粘贴一直是个坑，它用传输桥修复了，代码块一键复制

🎨 **主题自动跟随**——VS Code 深色/浅色切换，DSH 界面实时同步，不刺眼

📁 **工作区自动对齐**——切换文件夹，DSH 的 workspace 锚点跟着走，会话归档保留可恢复

🚀 **版本软校验 + 升级辅助**——检测到新版 dsh 自动提示，按你的安装方式（npx/npm 全局/nvm）推荐升级命令，终端预填不自动执行

💻 **跨平台**——macOS / Linux / Windows 全支持，CI 三平台实测；9 种语言界面

⚡ 怎么用？两步：

1. 先装 DSH：`npm i -g @deepseek-ai/dsh`
2. VS Code 扩展市场搜 **"DeepSeek Harness Web for VS Code"**（Antigravity 走 Open VSX 同样可装）

装完点活动栏图标，dsh 自动启动，DSH 界面就在标签页里等你啦 🎉

适合谁：用 DSH 跑 agent 工作流、又不想离开 VS Code 的开发者——省的是切换，留的是思路。
