## 标题

VS Code 里同时跑多个 DSH Agent 🔥

## 正文

一个 agent 不够用？修 bug、写测试、做评审，三个任务三个会话，来回切到头晕 😵💫

DeepSeek Harness Web for VS Code **v0.2.0** 上新——**多会话 × 多视图**：一个 dsh 实例，N 个会话并行，每个会话一个编辑器标签页。

🖥️ **多面板绑定多会话**
- `＋新建会话` 一键开新面板绑新会话，不用退出当前任务
- 每个标签页独立会话，并行流式输出互不干扰，不"串台"
- 关面板**不杀会话**——会话留在 DSH 里，列表点开随时恢复
- 重载工作区，全部面板自动复原，现场不丢

🗂️ **会话管理器侧边栏**
- 全部会话一目了然：标题 + 相对活跃时间（`5m`/`3h`/`2d`）
- `✎` 就地重命名，DSH 界面与标签页标题同步更新
- `✕` 归档进可展开的归档区，对应面板自动关闭，会话在 DSH 内保留不删
- 空白会话显示 "New Session"，不再每次启动堆积

🔗 依然与浏览器共享同一实例（`~/.dsh`）——会话、设置、插件两端互通
🎨 主题跟随 VS Code，深浅色实时同步

像浏览器多标签一样管理你的 AI 工作台——多任务并行，思路不断。

两步上车：
1. 安装 DeepSeek Harness：`npm i -g @deepseek-ai/dsh`
2. 扩展市场搜 "DeepSeek Harness Web for VS Code"（VS Code / Antigravity 同款）
